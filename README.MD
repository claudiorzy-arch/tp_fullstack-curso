# Trabajo practico fullstack

## Objetivo del proyecto

crear una pagina web capaz de mostrar estadisticas basicas sobre un texto,aplicando buenas practicas de desarrollo web con HTML Y CSS, ademas de utilizar Git y Github para el control de versiones del proyecto.

## Tecnologias utilizadas

-HTML5
-CSS
-GIT
-GITHUB

## Como se organizo el HTML

El HTML fue estructurado utilizando etiquetas semánticas para separar claramente las distintas secciones de la página. Se utilizó un header para el encabezado principal, un main para contener el contenido central y varias etiquetas section para dividir las funcionalidades de la aplicación, como el área de texto, las estadísticas y la sección de densidad de letras. También se emplearon div, label, input, button y otros elementos para organizar y agrupar los componentes de la interfaz.

## Como se resolvio el CSS

Los estilos se organizaron por secciones para facilitar su mantenimiento. Se utilizaron variables CSS definidas en :root para centralizar los colores del proyecto. Para la distribución y alineación de los elementos se empleó Flexbox, permitiendo organizar los componentes de manera flexible y ordenada. Además, se implementaron efectos hover para mejorar la experiencia visual y una Media Query para adaptar el diseño a dispositivos móviles.

## Dificultades encontradas

durante el desarrolllo surgieron algunas dificultaes relacionadas con al alineacion de elementos utilizados Flexbos, la correcta distribucion de espacion mediante margenes y padding, la creacion de barras de progreso para la seccion de densidad de letra. Tambien feu necesario comprender el flujo de trabajar de Git y Github para realizar commits, gestionar versiones y publicar el proyecto en un repositorio online
